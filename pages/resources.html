Frameworks

LLM & Agent Frameworks

🔗

LangChain

The go-to framework for building LLM-powered applications. Best for sequential chains, retrieval pipelines, and tool-augmented agents. Large ecosystem, excellent documentation.

PythonTypeScriptRAG
langchain.com →
📊

LangGraph

Built on LangChain, LangGraph adds stateful graph-based orchestration — essential for multi-agent systems with branching logic, cycles, and human-in-the-loop workflows.

AgentsStatefulMulti-Agent
langgraph docs →
🦙

LlamaIndex

Specialized in data indexing and retrieval for LLMs. Superior to LangChain for complex RAG use cases with structured data, SQL, and multi-document reasoning.

RAGIndexingPython
llamaindex.ai →
👥

CrewAI

Framework for orchestrating role-based AI agent teams. Intuitive API for defining agents with specific roles, tools, and collaboration patterns. Great for business process automation.

Multi-AgentRolesAutomation
crewai.com →
🔬

DSPy

Programmatic framework for optimizing LLM prompts and pipelines. If you're spending hours hand-writing prompts, DSPy can automatically optimize them against your metrics.

Prompt OptimizationStanford
dspy docs →
💬

Ollama

The simplest way to run open-source LLMs locally. One command to download and run Llama, Mistral, Phi, Gemma and dozens more. Essential for private and cost-free development.

Local LLMsOpen SourceFree
ollama.com →
Vector Storage

Vector Databases

📌

Pinecone

Managed vector database — easiest to get started for production RAG. Serverless tier available. Best choice when you don't want to manage infrastructure.

ManagedServerlessProduction
pinecone.io →
🧩

Weaviate

Open-source vector database with hybrid search built-in. Excellent for enterprise deployments needing both vector and keyword search without extra infrastructure.

Open SourceHybrid Search
weaviate.io →
🗄️

PGVector

Postgres extension adding vector search. If you already run Postgres, PGVector is the lowest-friction path to vector storage — no new database to manage.

PostgresSelf-hosted
GitHub →
🎯

ChromaDB

Lightweight, developer-friendly vector database. Perfect for local development, prototyping, and small-scale RAG applications. Runs in-memory or persisted locally.

LightweightDev-friendly

Evaluation & Observability

LLM Evaluation & Monitoring

📏

RAGAS

The standard evaluation framework for RAG systems. Measures faithfulness, answer relevancy, context recall, and precision automatically using LLM-as-judge methodology.

RAG EvalMetrics
ragas.io →
🔭

LangSmith

LangChain's observability platform for debugging, testing, and monitoring LLM applications. Excellent tracing UI that makes it easy to see exactly what's happening in complex chains.

ObservabilityTracing
langsmith →
📊

Weights & Biases (W&B)

ML experiment tracking and LLM evaluation. Particularly useful for fine-tuning runs, prompt versioning, and team collaboration on model evaluation.

Experiment TrackingFine-tuning
wandb.ai →
⚡

vLLM

High-throughput LLM serving engine. If you're deploying open-source models at scale, vLLM's PagedAttention delivers up to 24× higher throughput than naive Hugging Face serving.

ServingPerformanceOpen Source
